# OBLIVION ARENA 第3段階：効果音と環境音 設計書

- 作成日：2026-10-25
- 状態：ユーザーが判断を Claude に任せた（「あなたが決めて下さい」）ため、Claude の決定で確定
- 前提：第2段階（`docs/superpowers/specs/2026-10-25-stage2-combat-design.md`）の戦闘の上に作る

## 1. 目的
戦闘の手応えを音で強める。効果音と、谷を渡る風の環境音を入れる。音楽（曲）は後の段階。

## 2. 決定事項
| 項目 | 決定 |
|---|---|
| 範囲 | 効果音と環境音（風）。曲は後回し |
| 鳴らし方 | ブラウザ標準の Web Audio。新しいライブラリは使わない |
| 素材 | CC0 の効果音（Kenney の音素材パックなど）。必要ならコードで合成。入手元とライセンスを `ASSETS.md` に記録 |
| 形式 | モノラルの AAC（`.m4a`）。合計 1MB 以内 |
| マナーモード | iPhone のマナーモード（消音スイッチ）に従う |
| 消音ボタン | 左上のスタミナバーの下。押すたびに切り替え、次回も覚えておく（保存できないときは毎回オン） |

## 3. 対象外
曲（BGM）、声、ボイスチャット、音量のスライダー、立体音響（左右の定位）

## 4. 鳴らす音
| きっかけ | 音の名前 | 内容 | 群 |
|---|---|---|---|
| 攻撃1〜3段目の振り始め | `swing1`〜`swing3` | 短く鋭い風切り（3段目は重め） | 主人公 |
| 結晶獣に当たった | `hit` | 岩を叩く音＋結晶の澄んだ音 | 結晶獣 |
| 回避の始まり | `dodge` | 転がる音と布の擦れ | 主人公 |
| 主人公が攻撃を受けた | `hurt` | 鈍い衝撃 | 主人公 |
| 足音 | `step` | 歩き 0.5 秒、走り 0.32 秒おき。小さめ | 主人公 |
| 予告が出た | `warn` | 低く短い合図 | 結晶獣 |
| 叩きつけ・結晶の雨が落ちた | `slam`、`crystal` | 地面への重い衝撃／結晶が刺さる音 | 結晶獣 |
| 突進の始まり | `charge` | 地響き | 結晶獣 |
| 尻尾の回転の始まり | `spin` | 大きな風切り | 結晶獣 |
| よろめき | `stagger` | 結晶にひびが入る音 | 結晶獣 |
| 怒り状態になった | `enrage` | 低いうなり（合成でもよい） | 結晶獣 |
| 結晶獣を倒した | `shatter` | 結晶が砕ける音 | 結晶獣 |
| 勝ち／負け | `win`、`lose` | 短い明るい音／低い音 | 画面 |
| ボタン（もう一度・消音） | `click` | 小さなクリック | 画面 |
| 常に | `wind` | 谷を渡る風。繰り返し再生 | 環境 |

## 5. 音の出し方
- 最初のタッチかキー入力で音を有効にする。アプリが裏に回ったら止め、戻ったら再開する
- 音量：全体 0.8 × 群（主人公 0.7、結晶獣 0.9、画面 0.4、環境 0.25）
- 結晶獣の音は距離で小さくする：6m 以内は 1、25m で 0.4（その間は直線で）
- 毎回、音の高さを ±6% の範囲でずらす（同じ音でも聞き飽きないように）
- 同時に鳴る音は最大16。同じ音は 0.04 秒以内に重ねて鳴らさない
- 素材が読めないときは、その音だけ鳴らさずに続ける

## 6. プログラムの分け方
| ファイル | 役割 | 担当 |
|---|---|---|
| `src/audio/soundCues.js` | 前の frame と今の frame の戦いの状態を比べて、鳴らす音の一覧を返す（音は鳴らさない） | ChatGPT |
| `src/audio/sound.js` | 読み込み、再生、iPhone での有効化、消音、音量の配分、同時に鳴る数の上限 | Claude |
| 音の素材 | CC0 の入手、m4a への変換、`ASSETS.md` への記録 | Claude |
| `src/main.js`、`src/ui/hud.js` | 組み込み、消音ボタン | Claude |

## 7. 確認方法
- 自動テスト：鳴らす音の一覧（各きっかけで正しい音が1回だけ）、足音の間隔、音量の配分、距離による音量、同時に鳴る数の上限、同じ音の間隔、消音の保存と、保存できないときの扱い
- ブラウザ：エラーが出ないこと、音が読み込まれること
- iPhone 14：最初のタッチで音が出る、消音ボタン、マナーモード、裏に回って戻ったとき、音の大きさのバランス
