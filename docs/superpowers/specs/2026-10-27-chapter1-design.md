- 作成日：2026-10-27
- 状態：ユーザーの依頼文（物語・レベル設計・礼拝堂・操作・保存・検証の条件）と参考画像（霧の森4方向、廃れた礼拝堂4方向）を受け、ユーザーが通常の実装判断を事前承認（「確認を繰り返さず進める」）。依頼文の全文はチャットにあり、ここには採用した方針と決めた値を残す

## 採用方針
- 物語パートは、結晶獣戦とは別の three.js の Scene（`src/chapter/`）。主人公は同じ `knight.glb` を `createPlayer` で読み込み、同じ `playerActions`（移動・3段攻撃・回避・のけぞり）で動かす。外見と操作は結晶獣戦と同じ
- 進行・保存・会話・敵の頭脳は three.js も DOM も使わない純粋な部品（`src/story/`）にして、テストで確かめる。描画は `src/chapter/`、画面の文字は `src/ui/storyHud.js`
- 森と礼拝堂はコードで作る立体（地面の起伏・道・木の幹・岩・壁・門・橋・柱・長椅子・祭壇に当たり判定）。遠景の山だけ軽い背景。参考画像を板に貼る方式は使わない
- 地形・建物は Kenney Nature Kit（CC0）の木・岩・草と、コードで作る石壁・礼拝堂。参考画像の写実的な見た目は再現できない（低ポリゴンの既存の画風に合わせる）。この差は報告で明示する
- 敵「霧に侵された衛兵」は KayKit Skeletons の Skeleton_Warrior（CC0、主人公と同じ作者・同じ骨格）。主人公モデルは流用しない

## 決めた値
- 衛兵：体力 50、攻撃は予備動作 0.7 秒 → 当たる 0.15 秒（前方の扇 1.7m・100°、15ダメージ）→ 隙 0.9 秒。気づく距離 9m（見通しが通るときだけ）、持ち場から 14m で引き返す。攻撃は見通しが通るときだけ
- 会話：自動で進む字幕（1行 1.4 秒＋1文字 0.09 秒）。冒頭の目覚めと記憶の場面だけタップで送る（送りのタップは全画面の層が受け止め、攻撃へ伝わらない）。記憶はスキップできる
- 保存：`localStorage` の `oa-story`。`{ version: 1, phase, checkpoint, flags, seen, defeated }`。壊れていれば新規。復帰地点は「開始」「門の開放後」「礼拝堂到着」
- 死亡：直前の復帰地点へ。会話・門・倒した敵の記録はそのまま（倒していない敵だけ持ち場に戻る）
- カメラ：既存の三人称（水平360度、上下は 0.05〜0.9 rad）。壁・建物・太い幹に埋まらないよう、注視点からカメラへの線がぶつかる手前まで寄せる。地面より下へは行かない
