# THE SILENT CROWN タイトル画面 設計メモ

## 採用した方式（2.5D）
1枚の絵＋奥行きの地図（Depth Anything V2）から、遠景と近景を連続的な視差でずらす。複数の切り抜き層を板に貼る方式も比べたが、切り抜きの縁・黒いフリンジ・二重像の危険が大きく、元画像の維持で劣るため不採用。視差は小さく（絵の幅の 1.6%）、カメラは 37・53・61 秒の周期の波の和で、位置がずれ続けない。

| 要素 | 方式 | 本物の3Dか |
|---|---|---|
| 背景（空・城・谷・人物・木・地面） | 絵と奥行きの地図による視差（シェーダー） | 2.5D |
| 枝葉・草花・マント | 動かす場所の地図（masks の R・G）の範囲だけ、絵の読み取り位置をわずかにずらす | 2.5D |
| 雲・光の柱・谷の霧・地表の霧 | シェーダーで描く模様（空の地図・奥行きで範囲を限る） | 2.5D の上の効果 |
| 埃・花粉 | 点の粒（70、スマートフォンは 36） | 画面上の粒 |
| 古龍 | コードで作る立体（胴・首・尾の筒、頭と角、骨＋2層の膜の翼）。毎フレーム形を計算。空の地図（奥行き 0 の所）だけに描いて城・山・木の向こうに隠す | 本物の3D（ただし正射影で遠景に置く） |
| 題字・TAP TO BEGIN | HTML（題字は元の絵から切り出した透過画像） | — |

## 素材
- `scripts/build-silent-title.py`：題字の切り出し、LaMa による穴埋め、奥行きの推定、動かす場所の地図（枝葉・マント・空）
- 古龍のデザイン画像は、画像生成の手段がない（Artlist の残りなし）ため作っていない。立体は依頼文の特徴（風化した黒灰色、膜の翼、長い尾、控えめな角）からコードで作った

## 題字
- 背景の準備ができてから約2秒で現れ、そのあと 1 秒で消えて 1 秒で戻る（2 秒周期、ease-in-out）
- 動きを減らす設定では明滅しない。題字を消した跡は穴埋め済みなので、消えている間も元の文字は見えない

## 性能
- 背景は1枚の板の1回の描画（視差6回・模様最大4重）。スマートフォン（指で操作する端末）は模様2重・埃36
- タイトルの間は戦いの絵を描かない（準備のため一度だけ描いて上書き）
- WebGL が使えないときは止まった絵・題字・ボタンを出し、押したら理由を表示
